# FilmOne scene model assets

Google SigLIP2 Base image encoder exported to ONNX for FilmOne 0.5.0. Model weights are Apache-2.0; see LICENSE, NOTICE and manifest.json for provenance, exact hashes and sizes.

These public static model pieces support the private FilmOne web app. Photos are processed locally and are never uploaded here. The image encoder is unchanged except for ONNX export and output normalization. Text prototypes are precomputed separately. No Google or Megvii affiliation or endorsement is implied.
